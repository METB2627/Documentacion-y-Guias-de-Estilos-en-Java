Módulo 1: Introducción y Fundamentos
Nivel: Principiante

¿Qué es la Documentación en Java?

La documentación en Java es una parte integral del desarrollo de software profesional. En entornos empresariales, la documentación de calidad marca la diferencia entre un proyecto mantenible y uno inmanejable.

AspectoImpactoPrioridad
MantenimientoReduce tiempo de comprensión⭐⭐⭐⭐⭐
ColaboraciónFacilita trabajo en equipo⭐⭐⭐⭐⭐
OnboardingAcelera integración⭐⭐⭐⭐
📌 Nota: Los desarrolladores dedican entre 40% y 60% de su tiempo leyendo código. Una documentación adecuada reduce significativamente este tiempo.

Javadoc: El Estándar de Documentación

Javadoc es el generador oficial de documentación de API (Application Programming Interface, Interfaz de Programación de Aplicaciones) para Java. Fue creado por Sun Microsystems y pertenece a Oracle.

¿Qué es un Doclet?

Un Doclet es un programa Java que personaliza la salida de Javadoc.

Crear Doclet Personalizado

import com.sun.javadoc.*; public class MiDoclet { public static boolean start(RootDoc root) { ClassDoc[] clases = root.classes(); for (ClassDoc clase : clases) { System.out.println("Clase: " + clase.name()); MethodDoc[] metodos = clase.methods(); for (MethodDoc metodo : metodos) { System.out.println( " Método: " + metodo.name()); } } return true; } }

Módulo 13: Guía de Estilo de Java de Google
Nivel: Referencia Oficial

1. Introducción

Este documento sirve como la definición completa de los estándares de codificación de Google para el código fuente en Java™.

2. Aspectos Básicos

2.1 Nombre del Archivo

El nombre del archivo consiste en el nombre de la clase de nivel superior, más la extensión .java.

2.2 Codificación: UTF-8 (Unicode Transformation Format, Formato de Transformación Unicode)

Los archivos fuente están codificados en UTF-8.

2.3 Caracteres Especiales

  • El espacio horizontal ASCII (0x20) es el único espacio en blanco permitido
  • Los tabuladores no se utilizan para sangría
EjemploEvaluación
String unitAbbrev = "μs";✅ Mejor: claro
String unitAbbrev = "\u03bcs";❌ Deficiente: poco claro

3. Estructura del Archivo

3.1 Importaciones

// ❌ No permitido: import java.util.*; // ✅ Correcto: import java.util.List; import java.util.ArrayList;

3.2 Ordenación

  1. Todas las importaciones estáticas en un grupo
  2. Todas las no estáticas en otro grupo

4. Formato

4.1 Llaves: Estilo K & R (Kernighan and Ritchie, Kernighan y Ritchie)

return new MyClass() { @Override public void method() { if (condition()) { try { something(); } catch (ProblemException e) { recover(); } } else if (otherCondition()) { somethingElse(); } else { lastThing(); } } };

4.2 Bloques Vacíos

// ✅ Aceptable void doNothing() {} // ❌ No aceptable en multi-bloque try { doSomething(); } catch (Exception e) {}

4.3 Sangría: +2 espacios

4.4 Límite de Columna: 100

⚠️ Excepciones: URLs (Uniform Resource Locator, Localizador de Recursos Uniforme) largas, importaciones, bloques de texto.

4.5 Ajuste de Línea

MyLambda<String, Long, Object> lambda = (String label, Long value, Object obj) -> { ... }; Predicate<String> predicate = str -> longExpressionInvolving(str);

4.6 Espacios en Blanco

// Alineación horizontal no requerida private int x; private Color color; // Esto también es válido private int x; private Color color;

6. Prácticas de Programación

6.1 @Override: siempre utilizado

@Override public String toString() { return "..."; }

6.2 Excepciones no ignoradas

try { int i = Integer.parseInt(response); return handleNumericResponse(i); } catch (NumberFormatException _) { // No es numérico, continuar } return handleTextResponse(response);

6.3 Miembros estáticos

Foo.aStaticMethod(); // ✅ bueno aFoo.aStaticMethod(); // ❌ malo

7. Javadoc

7.1 Formato

/// El texto se escribe aquí, /// ajustado normalmente... public int method(String p1) { ... }
/** * Múltiples líneas de texto * se escriben aquí. */ public int method(String p1) { ... }

7.2 Fragmento de Resumen

Es una frase sustantiva o verbal, no una oración completa. Se capitaliza y puntuá como oración.

// ✅ Correcto: /// Devuelve el ID del cliente. // ❌ Incorrecto: /// @return el ID del cliente

7.3 Dónde se Utiliza

Como mínimo, Javadoc está presente para cada clase, miembro o componente visible.

💡 Excepciones: Miembros autoexplicativos, sobrescrituras, Javadoc no requerido.
